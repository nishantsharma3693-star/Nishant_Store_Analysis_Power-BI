# Nishant_Store_Analysis_Power-BI

An interactive Power BI dashboard project developed to track, analyze, and visualize online sales data across different regions of India. This project helps businesses gain insights into sales performance, customer behavior, profit trends, and product category analysis through dynamic visualizations and filters.

# Project Objective

The main objective of this project is to help an e-commerce business monitor and analyze sales data efficiently using Power BI dashboards and interactive reports.

# Key Features

* Built an interactive dashboard for online sales analysis
* Used filters, slicers, and drill-down features for better data exploration
* Connected multiple tables and created relationships for accurate analysis
* Created calculated measures and KPIs for business insights
* Added user-driven parameters and customized visualizations
* Implemented different chart types for better understanding of data

# Visualizations Used

* Clustured Column Chart
* Donut Chart
* Clustered Bar Chart
* Slicers and Filters
* KPI Cards

# Tools & Technologies

* Power BI Desktop
* Data Modeling
* Excel Dataset

# Insights Generated

* State-wise and category-wise sales performance
* Profit and revenue analysis
* Customer purchasing trends
* Monthly and quarterly sales trends
* Top-performing products and regions
